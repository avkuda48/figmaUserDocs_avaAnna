# Glossary

| Term                    | Definition                                                                                                     |
| ----------------------- | -------------------------------------------------------------------------------------------------------------- |
| **camelCase**           | Naming convention that involves no spaces and the first letter of each word capitalized besides the first word |
| **Figma**               | Collaborative software for designing and prototyping software                                                  |
| **Hex Code**            | String of 6 numbers and letters A-F that represent a specific colour                                           |
| **Toolbar**             | Element of an application's user interface that contains tools for the user to easily access                   |
| **User Interface (UI)** | Visual and interactive elements of an application                                                              |
